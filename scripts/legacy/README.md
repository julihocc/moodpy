# Retired repository scripts

These files were moved from the root with their contents preserved. They contain
old package assumptions and commands, including remote publishing, account
configuration, and GitHub issue creation. They are historical references, not
current automation; do not run them as part of authoring, testing, or cleanup.

Use [check_environment.py](../check_environment.py) for local environment checks,
the [development guide](../../docs/development.md) for building and testing, and
the gated GitHub publishing workflow for an explicitly requested release.
