# MoodPy agent entry point

Read [AGENTS.md](AGENTS.md) and [the canonical authoring guide](docs/authoring-guide.md).
These describe the supported workflow for collaborating with an educator and
creating reproducible Moodle question banks from Python recipes.

For educational content, start from the verified recipe catalog, save the quiz
brief, review representative questions, and export validated bank snapshots.
For maintenance, preserve public interfaces, test the installed wheel, and leave
existing submodule changes untouched. Follow [the development guide](docs/development.md).
The [documentation index](docs/README.md) distinguishes current guides from archives.
