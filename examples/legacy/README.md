# Historical examples

These scripts were moved from `examples/` with their topic folders and contents
preserved. They are references requiring verification, not supported recipes.
Some contain Sage syntax, Python 2 constructs, missing dependencies, global random
state, or unfinished migrations. Commands and paths inside them may be obsolete.

For reproducible question banks use the [authoring template](../agent_workflow/author_bank.py)
and [verified recipe catalog](../../docs/verified-recipes.md). The optional
[generator package](../../generators/README.md) provides separately tested notebook
replacements. Verify mathematical answers, dependencies, and Moodle grading before
adapting historical code into a new recipe.
